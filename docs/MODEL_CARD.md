# 模型卡

本仓库的模型都处于**研究用途**，不是医疗器械，未取得任何监管认证，也不构成诊断结论。所有性能数字以 [规则登记](../rules/metrics.json) 关联的评估报告为准；本卡不重复数字，只声明适用边界与失效方式。

## 预期用途

- 研究、教学、算法对比与方法复现。
- 在已授权、去标识的数据上产生辅助提示，供有资质的医生复核。
- 作为工作站里的一个分析任务，输出必定附带证据帧、适用范围与不确定性；证据不足时返回 `insufficient_evidence` 而不是给出结论。

## 非预期用途

- 不作为独立诊断依据，不替代医生签发报告。
- 不用于急诊分诊、危急病例判断或转诊决策的单独依据；此类情形按现行临床流程处理。
- 不用于未授权数据、任何商业用途，或未取得对应许可的场景。
- 不对成人、非本数据集分布或非本设备采集的影像作性能承诺。

## 适用人群与输入

- 训练与评估人群以各模型文档记录的数据集为准。EchoNet-Pediatric 为 0–18 岁儿童经胸心超；CAMUS 为成人 2CH/4CH；CardiacUDC 为两家医院的 A4C。
- 输入的视图、帧率、分辨率与预处理在各模型文档中固定；偏离这些条件时结果不具可比性。
- 视频需可解码且包含可判读的目标切面；不满足时模型应拒判。

## 已知失效方式

| 失效 | 表现 | 处理 |
| --- | --- | --- |
| 分布外输入 | 预测退化为接近常数的输出 | 先看预测分布的方差；方差过低时只报失效，不参与排序 |
| 切面缺失或质量过低 | 证据不足 | 返回 `insufficient_evidence` 并提示补采 |
| 单帧或短片段 | 时间信息不足 | 明确记录抽样帧数，不与完整检查的结果混比 |
| 标签口径不同 | 与临床报告不一致 | 以复核协议定义的参考标准为准，不把报告值当金标准 |
| 类别不平衡 | 阳性极少时指标不稳定 | 报告阳性例数与区间，标注探索性或方向性 |

## 证据与追溯

- 每个对外数字在 [rules/metrics.json](../rules/metrics.json) 的 `claims` 中登记，指向对应的 Release 评估报告。
- 未登记的指标数字会被 `scripts/check_redlines.py` 拦下，CI 与 pre-commit 使用同一脚本。
- 交付判据与当前状态见 [DELIVERABLES.md](DELIVERABLES.md)。

## 版本与更新
