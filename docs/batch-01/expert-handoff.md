## 请临床负责人先确认

| 项目 | 请确认的判定标准 |
| --- | --- |
| 心尖四腔（A4C） | 规定识别所需的解剖线索，以及右室聚焦等变体如何归类。结合项目任务确认四腔、房室瓣、心尖、房间隔和室间隔各自的显示要求。 |
| 胸骨旁短轴（PSAX） | 确认纳入的大动脉、二尖瓣、乳头肌、心尖等层面，并按层面列出最低可见结构。试标记录 PSAX 主类，能确定的层面写入 `structure_notes`。 |
| 其他、过渡、无法判断 | 清楚识别为其他切面时记「其他」。扫查中切面正在切换时记「过渡」。信息不足时记「无法判断」并写原因。正式表中使用标签字典已确认的代码。 |
| 灰阶与彩色多普勒 | 分别列出质量所需的关键结构、目标血流区域和允许的偏离。请明确遮挡、切面偏斜、增益异常、彩色溢出或伪影在什么情况下妨碍评估。 |
| 采集质量 | 请明确「可评估」「需补扫」「无法评估」的界限。判定依据是任务所需结构或区域的显示情况。解剖异常但结构显示充分的片段可评估，结构显示不足的片段应记录缺失项。 |

临床负责人可参考 [ASE 儿童经胸超声指南](https://www.asecho.org/guideline/comprehensive-pediatric-tte/) 确认结构清单和代表性边界例。

## 如何填写并回收

1. 先按视频编号打开获准访问的完整原始视频。截图及时间戳可帮助定位。冻结、扫查稳定性、短时出现的结构以及彩色多普勒表现，请回看连续画面。
2. 分别填写切面和质量。切面、质量或成像模式变化时另起一行，同一视频的确认区间不重叠。以交付原视频首帧为 0，按整数毫秒填写起止时间，包含起点并排除终点。
3. 在「片段标注」中填写片段编号 `segment_id`、视频编号 `clip_id`、`start_ms`、`end_ms`、可判定的 `view_code` 或 `quality_code` 和标注员代号。混合模式填写 `segment_mode`。用 `structure_notes` 记录可见或缺失的结构及短轴层面，用 `quality_reason` 记录需补扫、无法评估或不确定的原因。暂无法确认的标签可留空，状态保留「待复核」。
4. 请两位医生对同一批次分别提交独立标注。遇到切面、质量或区间边界分歧时，共同回看原片，由临床负责人记录最终结论与理由，并把已定稿的行标为「已确认」。
5. 请通过项目组批准的渠道回传两份原始标注、最终复核表和更新后的标签字典。表内使用去标识患儿编号和检查编号，由数据提供方维护对应关系。正式表、影像和身份映射按院方批准的权限管理。
