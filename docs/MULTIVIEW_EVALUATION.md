# 多切面征象评估研究协议

版本 0.2 · 送审稿 · 2026-11-22 · 待审定。与[征象标签定义](MULTIVIEW_LABELS.md)一并审阅。签核并确认数据授权后冻结协议、字典和分析脚本。当前工作站按操作者为本次检查指定的必要切面整理确认帧与已有复核任务证据。全局必采清单由 [#27](https://github.com/songconmaisaix31-design/echo-edge-training/issues/27) 跟踪。

## 研究对象与参考标准

- 以检查为单位，评估模型对已定义征象的识别及其证据是否支持人工复核。工作站交付限于待复核征象的证据和补采提示。低样本征象只用于提醒人工复核，处置和上转由临床人员按现行流程决定。
- 拟纳入签核年龄和指征内、具备授权、去标识患儿与中心编号、能回看源视频的儿童经胸心超检查。按中心登记连续纳入期间、筛选、排除原因、参考资料缺失及检查结果。符合纳入条件但缺切面或画面不足的检查留在拒判统计中。
- 两名有儿科心超阅片资质的读者按同版字典独立审阅，对模型结果、对方标签及划分设盲，分别提交判读、支持帧、反对帧及缺失切面。两次记录先冻结，再由第三名具备相应资质的读者仲裁并留存依据。无法判断的结果保留其状态及原因。
- 征象参考标准使用授权的院内资料。临床负责人签核可用参考检查、辅助资料和相对原检查的时间窗。参考缺失与超出时间窗分别统计。EchoNet-Pediatric 的 EF 和切面标签仅对应其原任务。[原始数据说明](ECHONET_PEDIATRIC.md)

## 数据隔离与冻结

- 训练、验证、测试按患儿和中心同时隔离，同一患儿的重复检查、视频和派生帧随患儿归组。数据负责人核对跨中心患儿映射及同源重复影像。按实际生效的分组检查 `patient_id` 和 `site_code`。[划分预检说明](TRAINING_DATA.md)
- 验证集用于选模型、校准和确定拒判阈值。独立测试之前冻结纳入排除标准、划分、标签、模型和阈值、统计脚本及样本量计划。测试集用于独立评价。协议变更须记录新版本、时间、原因及受影响数据，标明探索性分析。
- 样本量按各征象的参考阳性和阴性数、目标区间宽度、预计参考缺失、模型拒判及中心聚类估算。各征象最低样本量、亚组界点和发布阈值在接触独立测试结果前签核。样本不足时报告实际计数与限制。

## 终点和统计

| 终点 | 计算口径 |
| --- | --- |
| 主要 · 征象敏感度与特异度 | 分别以全部参考阳性和全部参考阴性检查为分母，以正确预测的阳性和阴性检查为分子。模型拒判和执行失败留在相应分母。 |
| 主要 · 证据不足与执行失败 | 以计划评估该征象的检查为分母，分别报告 `insufficient_evidence`、执行失败和结果缺失。 |
| 次要 · 可判读结果的条件指标 | 纳入参考明确且模型给出可判读结果的检查，同时报告覆盖率和分母。 |
| 次要 · 证据帧符合与切面覆盖 | 帧符合按同一媒体和源帧索引匹配，时间戳用于回看核对。切面覆盖以本检查要求的切面数为分母，以有已确认帧的必要切面数为分子。 |

按征象提交参考结果与模型结果的交叉表。参考不明确、未评估和资料缺失分列，保留在流程图和计数中。分母为零时记不可估计。按预先签核的年龄、中心、设备、可判读性和有效切面数分层，并标明探索性分析。按纳入中心、再按该中心患儿有放回重抽。跨中心复查仍随同一患儿参与重抽。报告百分位双侧 95% 区间。建议冻结随机种子 `42`、重抽次数 `2000`。不能可靠估计区间的亚组报告计数及限制。
