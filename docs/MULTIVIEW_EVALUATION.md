# 多切面征象评估研究协议草案

本草案等待临床负责人审定。工作站只整理本次检查指定的切面、人工确认的源帧及已有征象复核任务的证据。全局必采清单及其适用年龄、指征和版本由 [#27](https://github.com/songconmaisaix31-design/echo-edge-training/issues/27) 审定后接入。

## 标签与参考标准

- 切面标签绑定媒体 ID、从 0 开始的源帧索引和原始时间戳。只有人工确认的独立源帧进入覆盖统计。多切面覆盖不足指缺少已确认的证据帧。
- 每条可疑征象绑定至少一个支持证据帧，另记录反对证据与缺失证据。未复核、视野外和图像不可判读分别记录。缺失或未知证据不能用作阴性标签。
- 两名具备儿科心超阅片资质的读者独立标记切面、可判读性和征象，并对研究模型结果设盲。分歧由第三名合格读者仲裁，保留两次独立判读及仲裁记录。具体征象定义、模糊病例和排除条件由临床负责人在收集阶段确认。
- 低样本征象的研究结果只用于提示人工复核。涉及临床处置和上转时，由临床人员按现行流程作决定。

## 样本与统计

- 纳入已授权且具备去标识患儿编号、中心编号和标准化参考标注的检查。重复检查、视频及派生帧随患儿进入同一划分。遇到同一患儿跨划分、同一中心跨划分或隔离标识缺失时，数据预检须报错并返回非零退出码。
- 隔离划分训练、验证、测试中心及患儿。冻结版本、划分、标签、安全阈值和主要终点后运行独立测试。EchoNet-Pediatric 公开的射血分数和切面标签不能用于此处的先心病征象或诊断训练。
- 主要终点以检查为单位，分别报告征象敏感度、特异度和证据不足比例。次要终点包括支持帧与专家标注的符合率，以及按切面统计的证据覆盖率。报告分母、排除与证据不足计数，并保留包含拒判的结果分布。
- 按年龄段、中心、设备、图像质量和可用切面数报告亚组。样本不足的亚组报告样本数及估计限制，保留未判读结果。置信区间使用按中心、患儿分层聚类的百分位 bootstrap，整组保留同一患儿的检查，报告双侧 95% 区间。中心数不足时标注估计限制。

技术、参考标准、数据划分与亚组按 STARD-AI 2025 报告。独立评价前，工作站结果只展示带证据的可疑征象与补充资料提示。[STARD-AI 主文献](https://doi.org/10.1038/s41591-025-03953-8)
