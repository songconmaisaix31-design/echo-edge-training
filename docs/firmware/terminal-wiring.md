# 终端接线（EdgeTerminal 固件）

对应 issue #2 / #4 / #5 / #6。所有引脚都避开禁区：`43/44`（UART0 调试口）、`26~37`（Flash/PSRAM）、
`19/20`（USB）、`17/18`（ECW 桥）、`41/42`（屏 I²C）。

## 零、本批实际到手的硬件

套件的 `modules/` 里有 37 个模块定义，但实物只有四个。这直接决定了哪些 issue 能验收：

| 器件 | 有无 | 后果 |
| --- | --- | --- |
| SSD1306 128×64 屏 | ✅ 有 | — |
| GXHT30C 温湿度 | ✅ 有 | #2 的温度、湿度两项可验收 |
| ITR9909 红外 | ✅ 有 | **只有比较器 DO，没有模拟通道** → #3 的脉率采不到 |
| SYN6288E 语音合成 | ✅ 有 | #4 的播报项可验收 |
| BMP388 气压 | ❌ 无 | #2 的气压项无法验收 |
| 振动马达 | ❌ 无 | #4 的振动项无法验收 |
| MG90S 舵机 ×2 | ❌ 无 | #5 整体无法验收 |

固件对这四类缺失都做了处理：气压/温湿度按"离线"降级显示 `--` 并每 2 秒重探；
舵机改成首次发命令才初始化 PWM，不占引脚；振动只驱动 GPIO，没有马达不报错。

下面的接线表保留了完整形态 —— 硬件补齐后按表接上即可，代码不用改。

## 一、I²C 总线：屏 + 温湿度 + 气压（issue #2）

三个器件**并联在同一条总线**上，地址不冲突，不必分开接。

| 器件 | 地址 | 模块针脚定义 | 接到 ESP32-S3 |
| --- | --- | --- | --- |
| SSD1306 屏 | `0x3C` | GND / VCC / SCL / SDA（丝印） | GND / 3V3 / **GPIO42** / **GPIO41** |
| GXHT30C 温湿度 | `0x44` | CN1：1=3V3，2/3=SCL/SDA（**冲突**），4=GND | 3V3 / GPIO42 / GPIO41 / GND |
| BMP388 气压 | `0x76` | CN2：1=VCC，2=SCL，3=SDA，4=GND | 3V3 / GPIO42 / GPIO41 / GND |

### 温湿度的 pin2/pin3 是官方标注的雷区

`module.json` 原文：

> `connection_status: blocked`
> 禁止直接按表通电通信：图纸文字与网标互换，须连续性测量实物 pin2/pin3 并由供货方冻结线序。

即**按图纸接大概率是反的**。处理办法：

1. 先按「pin2→SCL(GPIO42)、pin3→SDA(GPIO41)」接
2. 上电，发 `SCAN`。看到 `0x44` 就成了
3. 没有 `0x44` 就把这两根对调，再 `SCAN`
4. 两种接法都没有 → 先怀疑 VCC 和 GND，不是信号线

固件每 2 秒自动重探一次，**改完线不用复位、不用重新烧录**，几秒内屏上就会自己变成有效读数。
这条正好是 issue #2 验收标准第 4 条的实现方式。

## 二、语音与振动（issue #4）

### SYN6288E 语音合成

| 模块 | ESP32-S3 | 说明 |
| --- | --- | --- |
| `TXD` | `GPIO6` | 模块发 → ESP32 收 |
| `RXD` | `GPIO5` | ESP32 发 → 模块收 |
| `VCC` | 按模块丝印（多为 5V） | **不要**直接吃 3V3 如果丝印写 5V |
| `GND` | `GND` | 共地 |

波特率 **9600 8N1**，与主串口（115200）独立，走 UART2。

帧格式：`0xFD | lenH | lenL | 0x01 | 0x00 | data | XOR`，`0x00` = GB2312。
固件里预置了 8 条提示语（避免运行时 UTF-8→GB2312 转码），`TTS 1` 到 `TTS 8`。

### 振动马达

| 马达 | ESP32-S3 |
| --- | --- |
| `+` | `GPIO4` |
| `-` | `GND` |

**注意**：金币马达额定电流常超过 GPIO 的 12 mA 上限。若模块不带驱动三极管，
必须外接 NPN/MOSFET 加续流二极管，否则会拉垮 GPIO 甚至损伤 IO。

## 三、双舵机（issue #5）

| 舵机 | 信号线 | 电源 |
| --- | --- | --- |
| 舵机 1 | `GPIO7` | **独立稳压电源** |
| 舵机 2 | `GPIO15` | **独立稳压电源** |

- 50 Hz PWM，脉宽 0.5–2.5 ms 对应 0–180°
- **舵机电源绝对不能从 ESP32 的 3V3 取**。MG90S 堵转电流可达 700 mA 以上，
  会把主控拉复位。外部电源的地必须和 ESP32 的 GND 接在一起。
- 上电时固件先把两只舵机置到 90°（1.5 ms），避免上电瞬间乱甩

验收标准里「两只同时启动时记录电压」，用万用表监外部电源输出端即可。

## 四、电脑联动（issue #6）

不需要额外接线，走 ESP32 的 USB 串口（CH343 → `COM4`），115200 8N1。

协议：

```
电脑 → 终端:  HINT <1..8>      触发预置提示：屏 + 播报 + 振动
              HINT <英文文本>   只上屏，不播报
终端 → 电脑:  ACK,<seq>        回执，seq 单调递增
              ENV,<t>,<rh>,<p>,<tv>,<rv>,<pv>,<ms>   每秒一行环境读数
```

`ACK` 的序号与 `HINT` 一一对应，30 分钟测试时「发送数 / 到达数」直接用
`seq` 最大值和实际收到的 `ACK` 条数比对。

`ENV` 行的三个 `0/1` 是有效性标志，用来统计「采样丢失」——
某一位从 1 变 0 且不是人为断线，就是一次丢样。

## 五、上电自检顺序

固件 `setup()` 的做法，每步都有日志，卡在哪一步一眼能看出来：

1. 振动马达置低（防止上电误振）
2. 红外 DO 设为输入
3. UART2 起 9600（语音）
4. 两只舵机置 90°
5. I²C 总线上线，初始化屏
6. 探测温湿度、气压，各打印在线/离线
7. 画第一帧，输出第一行读数

屏没起来时会自动跑一次 `SCAN` 把总线现状打出来，不用另外发命令。
