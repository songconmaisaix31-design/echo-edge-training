# 儿童经胸心超训练数据交付要求

本项目从儿童经胸心超视频抽取单帧，同时训练切面分类和采集质量分类。影像团队提供可解码的去标识 cine，临床团队提供确认后的区间标注和标签定义。

## 交付内容

- 一份填好的 `.xlsx` 标注工作簿。请从[儿童心超标注模板](../templates/儿童心超标注模板.xlsx)另存一份，保留工作表名称、前四行及列顺序，从第 5 行填写。编号、代码和路径使用文本，时间使用整数毫秒，单元格填实际值。
- 一个影像目录或 ZIP，其中每个文件对应「视频清单」的一行。目录、ZIP 和已填写工作簿通过项目约定的院内渠道交付。公开仓库只存放空白模板。
- `relative_path` 相对于传给 `--media` 的目录根或 ZIP 根。例如影像目录中存放 `clips/study-001/clip-001.dcm`，表内填同一路径。ZIP 有额外的外层目录时，路径包含该目录。保留文件名、扩展名和大小写，路径统一用 `/`，同一路径只登记一次。

### 影像文件

- 优先交付原始二维超声多帧 DICOM cine，一段对应一个 DICOM 文件。可使用 `.dcm`、`.dicom`、`.ima` 或无扩展名的 DICOM 文件。对象应为超声多帧存储 SOP Class UID `1.2.840.10008.5.1.4.1.1.3.1`，或兼容的旧类 `1.2.840.10008.5.1.4.1.1.3`。`Modality` 应为 `US`，文件至少包含两帧。`DICOMDIR`、单帧影像、空间切片和增强型 3D/4D 超声对象均不适用于当前入口。
- 保留 `NumberOfFrames`、`FrameIncrementPointer`、其指向的时间字段、传输语法、像素数据和颜色解释。`FrameTime` 为正数毫秒间隔。`FrameTimeVector` 的项数必须与帧数一致，首项为零，各项是非负的相邻帧时间增量，且至少一项为正。程序按时间字段计算相对于首帧的时间。播放帧率字段无法代替该时间信息。 [DICOM Cine Module](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.7.6.5.html)
- 保留原始画幅、灰阶和彩色多普勒像素。提交 AVI、MP4 或 MOV 时，文件须保留可解码的视频流和单调呈现时间戳，工作簿按交付文件核对时间。H.264/HEVC 封装在 DICOM 内的对象目前需要单独适配。
- 交付前由数据提供方核查 DICOM 元数据、私有字段、烧录在像素中的文字、文件名、视频音轨和工作簿。使用院方生成的去标识编号，身份映射表保留在院内。去标识时保留采样所需的时间字段及彩色像素。 [DICOM 去标识规范](https://dicom.nema.org/medical/dicom/current/output/chtml/part15/sect_E.3.html)

## Excel 字段

### 标签字典

由儿童心超负责人在批量标注前确定类别和判定口径。两个任务各需至少两种有效标签。

| 字段 | 类型 | 填写要求 |
| --- | --- | --- |
| `task` | 文本 | 必填。`view` 表示切面，`quality` 表示采集质量。 |
| `label_code` | 文本 | 必填。同一任务内不得重复。用稳定代码，与片段标注中的值逐字一致。 |
| `display_name` | 文本 | 必填。临床可读的类别名称。 |
| `definition` | 文本 | 必填。说明如何判定该类、如何与相近类别区分。 |
| `mode_scope` | 文本 | 建议填写适用的成像模式，供临床标注和复核。 |
| `required_structures` | 文本 | 建议填写该切面应显示的目标结构，以及什么情况视为可评估。 |

### 视频清单

| 字段 | 类型 | 填写要求 |
| --- | --- | --- |
| `clip_id` | 文本 | 必填。不同视频使用不同编号。 |
| `patient_id` | 文本 | 必填。同一患儿在所有检查、重访、补扫和同源转码中使用同一个去标识编号。多中心交付时须避免不同患儿编号碰撞。 |
| `study_id` | 文本 | 必填。一次检查可有多个视频，同一个检查编号只关联一个患儿。 |
| `relative_path` | 文本 | 必填。影像目录或 ZIP 中的相对路径。 |
| `mode` | 文本 | 必填。记录视频成像模式，如二维灰阶或彩色多普勒。混合模式可在片段级补充。 |
| `duration_ms` | 整数 | 可空。填写时为大于零的毫秒数，已确认区间的结束时间不得超过该值。末帧结束时间未可靠记录时可留空。 |
| `site_code` | 文本 | 已分组影像必填，使用稳定的采集中心代号。同一中心的全部影像使用同一个代号。 |
| `age_band`、`device_model`、`probe_model` | 文本 | 建议填写年龄段、设备和探头型号，用于追查采集条件及覆盖情况。 |
| `split` | 文本 | 可填 `train`、`val`、`test`，或统一留空。详见分组要求。 |

### 片段标注

| 字段 | 类型 | 填写要求 |
| --- | --- | --- |
| `segment_id` | 文本 | 已确认行必填，全表不得重复。 |
| `clip_id` | 文本 | 已确认行必填。须指向有效的视频清单行。 |
| `start_ms`、`end_ms` | 整数 | 已确认行必填。从交付文件的首个呈现帧计时，首帧为 `0`。区间为 `[start_ms, end_ms)`，含起点，结束点排除在外。`0 ≤ start_ms < end_ms`，同一视频的已确认区间不得重叠，每个区间至少包含一张实际存在且可解码的源帧。 |
| `view_code`、`quality_code` | 文本 | 已确认行至少填一项。各自引用对应任务的标签代码。该任务尚无法判定时留空，训练忽略此任务的监督。 |
| `review_status` | 文本 | 最终采用的区间填 `已确认`，未定稿可填 `待复核` 或留空。仅 `已确认` 的行进入监督训练。 |
| `quality_reason`、`structure_notes` | 文本 | 建议记录质量问题和结构可评估性，供复核。 |
| `annotator_id`、`segment_mode` | 文本 | 建议记录标注员代号。混合模式文件建议记录每段实际成像模式。 |

切面、成像模式或质量判定改变时，应拆成多个连续且不重叠的区间。`view_code` 标识采集切面，`quality_code` 依据相应切面和模式下所需结构是否充分显示。病理异常时也可能采集合格。冻结、扫查是否稳定等需要连续画面才能判断的问题，可记入 `quality_reason`。单帧无法确定的质量标签留空。标注有分歧时，仅将复核后的最终区间设为 `已确认`。

## 分组与首批覆盖

- 手工分组时，每名有确认标注的患儿都须明确归组。该患儿的所有文件继承同一分组，分组栏统一填写可方便核对。若所有 `split` 都留空，程序按患儿自动分为 `train` 和 `val`，默认验证比例为 `0.2`，随机种子为 `42`。如需固定独立测试集，请手工设为 `test`。
- 预检核对手工、继承和自动划分的实际结果。每名患儿和每个中心都只能出现在 `train`、`val`、`test` 中的一个组。跨组或缺少中心代号时返回退出码 `1`，在读取影像前写出预检报告。自动划分出现中心冲突时，按中心和患儿手工调整分组后重新预检。
- `train` 组须覆盖标签字典中的每个有效类别。`val` 组须至少有切面和质量各一项有效标注，并来自独立患儿。为便于评估，建议验证组也覆盖各类别。`test` 组参加数据预检，在当前训练入口中保留为独立数据。
- 先覆盖团队实际使用的设备和采集方式。临床团队可先对同一小批去标识影像校准标注口径，检查标签是否能稳定判断，再扩充各类别与低质量情形。每个类别尽量覆盖多名患儿，并核对同一检查的重复导出和相近片段。

## 交付前核验

拿到完整资料后，按 [README](../README.md) 用正式训练参数执行 `train --preflight-only`。JSON 报告会列出视频清单行号、片段行号、可抽取的帧数、首末源帧及时间戳、分组和标签覆盖。预检通过代表该批数据通过当前读入和抽帧检查。临床标注准确性、设备导出保真度以及不同编号是否对应同一患儿，由交付和复核人员核对。

使用已安装训练依赖的 Python 运行 `python -m unittest -v test_split_preflight`，可核对同一患儿跨划分、同一中心跨划分和缺少中心代号时的退出码及报告行号。测试从空白模板和两篇公开病例的清单信息创建独立工作簿，分组只用于验收。 [POCUS Journal 公开病例](https://pocusjournal.com/article/2021-06-01p10-12/) · [CASE 公开病例系列](https://doi.org/10.1016/j.case.2021.08.002)

现有公开样本验证了多帧 DICOM 读取、固定帧间隔抽帧和 RGB 色彩保留。变帧间隔时间计算另外用真实血管造影 DICOM 核对。团队设备导出的变帧间隔超声和二维彩色多普勒原片仍需逐批预检与人工复核。
