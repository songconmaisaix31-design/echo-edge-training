# Echo Edge V1.0 全系统端到端验收

**结论：研究用途核心流程通过。前端可进入收尾，但尚未达到全系统签收条件。后端可开展切面模型模式的本地联调，新增模型及证据输出仍需各自验收。**

## 环境与证据

- 当前分支为 `feature/web-ui`，以现有未提交工作树为验收对象。监听检查确认 Web 5181、FastAPI 8019 均在运行，Web 代理的能力接口返回 Stanford PyTorch CPU FP32。
- 实际写入测试使用独立 Vite 5186 / Uvicorn 8026、临时 SQLite 与临时影像目录。测试库实际执行 Alembic 到 0005 后启动。未写入现有临床数据或终止在用服务。
- 使用 Playwright Chromium、真实 HTTP 请求、现有非患者视频 fixture.mp4；正常模型测试使用真实 Stanford 权重。失败与超时采用测试注入，遗留任务使用隔离数据库构造后走实际 FastAPI 启动。模型得分不作为准确率评估。
- 后端 pytest **6 passed**，前端 TypeScript 与 Vite 构建 **PASS**。Vite 配置加载和依赖模块指令提示未阻断构建。浏览器首次采用请求转发夹具时因测试上下文提前关闭退出，改用独立 Vite 实际代理后重新完成验证。

## 跨模块复现路径

在独立环境创建患儿并编辑，使用其 ID 新建两次检查。向第一条上传两段视频并提交切面分析任务。查询检查和影像历史，再用浏览器打开该检查的详情和辅助诊断页。刷新后确认切面结论仍在，进入多切面页面逐帧与独立播放并保存整理记录。以病例条目 API 保存人工意见及报告草稿，到报告中心读回和下载。查询另一检查的影像、分析历史及报告导出，验证没有串数据。此流程混合浏览器和 API，未声明每一步均由网页点击完成。
