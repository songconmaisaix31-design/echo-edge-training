# MOCE 选手开发资料包 1.0.0-alpha.1

本包提供接线资料、模块驱动、公共 BSP、Board 和无业务的平台基础工程。选手自行实现应用，可让 Codex 从本目录 SKILL.md 和 MODULES.md 按需读取。

阅读顺序：[模块索引](MODULES.md) → 模块 WIRING.md/API.md → 所选平台 README → 空基础工程 → 自己编写应用。首次供电前核对实物版本、pin1、供电及共地；接头形状相同不保证电气兼容。

软件范围：原资料中的 39 个独立模块；36 个外设/供电模块位于 modules/，F407 与 ECW6700 主控及 F407 转接板位于 platforms/。原包没有 ESP32/CH32/F103 主控闭环依赖，本交付不扩展这些主控支持。平台无关驱动不表示所有硬件/模式均已验证。

没有应用例程、内部回归夹具、完整电路图、PCB、BOM、业务记录和后台资料。保留 BSP/Board/驱动源码，因此接口实现、芯片资源和引脚映射仍可被读取；此形式不能隐藏全部实现。SDK/编译器的大型下载独立完成；ST 必要固定 SDK 源码已附，ECW 原厂 P12 和匹配扩展须按平台指导准备。

接线依据用户确认的第一批/第二批原理图。图纸中的冲突和缺失见 [OPEN-ITEMS.md](OPEN-ITEMS.md)，尚未全部实物确认，不能宣称所有模块均已闭环。验证范围见 [VALIDATION.md](VALIDATION.md)。文件身份见 manifest.json 和 SHA256SUMS。源码作者/第三方许可证保留原声明；本整理不额外授予原版权之外的使用权。
