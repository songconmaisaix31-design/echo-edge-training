# 矩阵键盘 V1：驱动接入

公共头文件：[tm1650.h](drivers/common/tm1650.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus tm1650_init(Tm1650 *device, const Tm1650Config *config);
BspStatus tm1650_read(Tm1650 *device, Tm1650Reading *reading);
void tm1650_deinit(Tm1650 *device);
```

源文件依赖：`bsp_i2c.h`、`string.h`、`tm1650.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 扫描控制芯片 | TM1650-SOP16-TA1809D  |
| 实体按键数量 | 16 个 |
| 按键矩阵结构 | 4×4；ROW接DIG1～DIG4，COL接KI1～KI4  |
| 键码数据格式 | 8位，MSB先传；P6为按下／释放状态位  |
| 按键读取命令 | 0x4F，为手册定义的线上命令字节，不直接作为7位I²C地址填写  |
| 扫描使能要求 | 读键前必须处于手册规定的开显示扫描状态  |
| 多键处理规则 | 支持特定KI1＋KI2组合；其他多键按优先级处理，不是任意多键无冲  |

I2C 键盘，不是直接扫描裸矩阵引脚。
