# 摇杆 V1：驱动接入

公共头文件：[joystick.h](drivers/common/joystick.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus joystick_init(Joystick *self, const JoystickConfig *config);
BspStatus joystick_read(Joystick *self, JoystickSample *out);
```

源文件依赖：`bsp_adc.h`、`bsp_gpio.h`、`joystick.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 输入通道组成 | 两轴模拟位置输入＋一路按压开关  |
| 按键有效电平 | 按下低，释放高  |
| 回中机制 | 松手后机械回中，中心值需校准  |
| 回中输出范围 | 手册5V测试条件下为供电的41%～59%；不是中心精确50% % |
| 轴方向映射 | AO1、AO2对  |

双 ADC 加按键输入；VCC 范围待确认，AO 不得超过主控 ADC 范围。

验证：本交付不包含应用例程，也不把旧发布文字中的“已验证”继承为本包实机结论。逐模块目标编译与实机状态见根目录 VALIDATION.md。
