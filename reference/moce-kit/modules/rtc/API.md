# 实时时钟 V1：驱动接入

公共头文件：[rv3028.h](drivers/common/rv3028.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus rv3028_init(Rv3028 *device, const Rv3028Config *config);
BspStatus rv3028_read(Rv3028 *device, Rv3028Reading *reading);
BspStatus rv3028_set_datetime(Rv3028 *device, const Rv3028DateTime *time);
void rv3028_deinit(Rv3028 *device);
```

源文件依赖：`bsp_i2c.h`、`rv3028.h`、`string.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 核心RTC型号 | RV-3028-C7-32.768kHz-1ppm-TA-QC  |
| I²C地址 | 0x52，7位地址；线上写地址字节0xA4、读地址字节0xA5  |
| I²C最高速率 | 器件支持400kHz；实际总线还需满足线长、电容和上拉条件 kHz |
| 涓流充电约束 | 使用CR1220时必须禁用，TCE=0  |
| 外部辅助信号 | CLKOUT、INT未引出，EVI接地  |
| 断电保持验证状态 | 后备切换配置、断电保持时间及恢复后时间有效性待实测  |

图注 3.3V；7bit 地址 0x52；CR1220 为不可充电电池，禁止开启涓流充电。
