# 光敏电阻 V1：驱动接入

公共头文件：[gl5506.h](drivers/common/gl5506.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus gl5506_init(Gl5506 *device, const Gl5506Config *config);
BspStatus gl5506_read(const Gl5506 *device, Gl5506Reading *out);
BspStatus gl5506_read_diagnostic(const Gl5506 *device, Gl5506Reading *out, Gl5506Diagnostic *diagnostic);
```

源文件依赖：`bsp_adc.h`、`gl5506.h`、`math.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 光敏电阻型号 | GL5506（4～7kΩ）  |
| 模拟输出通道数 | 1 路 |
| 分压上拉电阻 | 10 kΩ |
| 光照与输出变化方向 | 相同供电和负载条件下，光照增强时AO电压下降，光照减弱时升高  |
| 响应时间（器件） | 手册列示上升30ms、下降30ms；不作为整板最大响应时间保证 ms |
