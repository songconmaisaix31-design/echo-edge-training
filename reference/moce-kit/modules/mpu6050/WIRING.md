# 陀螺仪 V1：接线

适用硬件：V1.0，第一批/第二批图纸；以相同硬件修订为前提。

连接器：U2。针号是图纸接点编号；未提供实物插口观察面或线色定义，必须按实物 pin1 标记确认方向。

| 针号 | 模块侧信号 |
|---|---|
| 1 | 3V3 |
| 2 | SCL |
| 3 | SDA |
| 4 | GND |

I2C，AD0 接地时 7bit 地址 0x68；不传输左移后的地址。

主控侧映射见所选平台的 Board；UART 按方向交叉，I2C/SPI 按同名信号连接。不同供电轨不能因接头相同而直通。
