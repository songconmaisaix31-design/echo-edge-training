# 陀螺仪 V1：驱动接入

公共头文件：[mpu6050.h](drivers/common/mpu6050.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus mpu6050_init(Mpu6050 *device, const Mpu6050Config *config);
BspStatus mpu6050_read_raw(Mpu6050 *device, Mpu6050Raw *out);
BspStatus mpu6050_convert(const Mpu6050Raw *raw, Mpu6050Sample *out);
BspStatus mpu6050_calculate_tilt(const Mpu6050Raw *raw, Mpu6050Tilt *out);
BspStatus mpu6050_deinit(Mpu6050 *device);
```

源文件依赖：`bsp_i2c.h`、`limits.h`、`math.h`、`mpu6050.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 核心传感器型号 | MPU-6050  |
| 加速度可选满量程 | ±2、±4、±8、±16；通过配置选择 g |
| 加速度灵敏度换算系数 | ±2g：16384；±4g：8192；±8g：4096；±16g：2048 LSB/g |
| 角速度可选满量程 | ±250、±500、±1000、±2000；通过配置选择 °/s |
| 角速度灵敏度换算系数 | ±250°/s：131；±500°/s：65.5；±1000°/s：32.8；±2000°/s：16.4 LSB/(°/s) |
| 加速度与角速度数据位宽 | 每轴16位；不代表16位有效精度 bit |
| 当前硬件I²C地址 | 0x68，7位地址，AD0接地  |
| I²C支持速率 | 支持100kHz标准模式及400kHz快速模式；实际速率受总线条件约束 kHz |
| 芯片FIFO容量 | 1024；需要驱动配置后使用 Byte |
| INT中断引出状态 | 当前原理图INT未连接外部接口  |

I2C，AD0 接地时 7bit 地址 0x68；不传输左移后的地址。
