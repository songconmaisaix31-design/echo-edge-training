# 触摸屏 V1：接线

适用硬件：V1.0，第一批/第二批图纸；以相同硬件修订为前提。

连接器：U1。针号是图纸接点编号；未提供实物插口观察面或线色定义，必须按实物 pin1 标记确认方向。

| 针号 | 模块侧信号 |
|---|---|
| 1 | 3V3 |
| 2 | BLK |
| 3 | S_DAT |
| 4 | S_RES |
| 5 | S_CS |
| 6 | S_CLK |
| 7 | WR/DC |
| 8 | T_RES |
| 9 | T_SCL |
| 10 | T_SDA |
| 11 | T_INT |
| 12 | GND |

屏 SPI 与触摸 I2C 分别初始化；BLK/复位/IRQ 均需按 Board 的独立资源配置。

主控侧映射见所选平台的 Board；UART 按方向交叉，I2C/SPI 按同名信号连接。不同供电轨不能因接头相同而直通。
