# 直流有刷电机驱动 V1：接线

适用硬件：V1.0，第一批/第二批图纸；以相同硬件修订为前提。

连接器：GH8。针号是图纸接点编号；未提供实物插口观察面或线色定义，必须按实物 pin1 标记确认方向。

| 针号 | 模块侧信号 |
|---|---|
| 1 | PWMA |
| 2 | AIN2 |
| 3 | AIN1 |
| 4 | VCC |
| 5 | GND |
| 6 | BIN1 |
| 7 | BIN2 |
| 8 | PWMB |

第一批 TB6612；VM 独立供电。不要套用第二批 AT8236 的 GH10 线序。VCC/VM 范围须确认。

主控侧映射见所选平台的 Board；UART 按方向交叉，I2C/SPI 按同名信号连接。不同供电轨不能因接头相同而直通。
