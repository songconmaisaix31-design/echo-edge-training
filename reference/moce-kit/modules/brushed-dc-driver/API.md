# 直流有刷电机驱动 V1：驱动接入

公共头文件：[tb6612.h](drivers/common/tb6612.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus tb6612_init(Tb6612 *device, const Tb6612Config *config);
BspStatus tb6612_drive(Tb6612 *device, int16_t duty_bp);
BspStatus tb6612_stop(Tb6612 *device, Tb6612StopMode mode);
BspStatus tb6612_deinit(Tb6612 *device);
```

源文件依赖：`bsp_gpio.h`、`bsp_pwm.h`、`tb6612.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 核心驱动芯片 | TB6612FNG，双通道H桥有刷直流电机驱动  |
| STBY硬件配置 | STBY直接连接3.3V，未引出独立待机控制  |
| 芯片PWM频率上限 | 100；属于芯片工作范围上限，实际使用频率需考虑损耗、噪声和温升 kHz |
| 电机反馈能力 | 本原理图未设置电流检测、转速或位置反馈电路，模块采用开环驱动  |

第一批 TB6612；VM 独立供电。不要套用第二批 AT8236 的 GH10 线序。VCC/VM 范围须确认。
