# 温湿度传感器 V1：驱动接入

公共头文件：[gxht30c.h](drivers/common/gxht30c.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus gxht30c_init(Gxht30c *sensor, const Gxht30cConfig *config);
BspStatus gxht30c_measure(Gxht30c *sensor, Gxht30cReading *out);
void gxht30c_deinit(Gxht30c *sensor);
```

源文件依赖：`bsp_i2c.h`、`gxht30c.h`、`limits.h`、`string.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 核心器件型号 | GXHT30C，带不可揭除的防尘透气膜  |
| I²C地址 | 0x44，7位地址，ADDR接地  |
| 温度测量范围 | −45～130， ℃ |
| 相对湿度测量范围 | 0～100， %RH |
| I²C速率能力 | 芯片支持最高1MHz；整板可用速率需结合总线电容、线长及上拉验证 kHz |
| CRC算法 | CRC-8，多项式0x31，初值0xFF，不反射，最终异或0x00；校验前面的两字节数据  |
| 外部辅助信号 | ALERT、nRESET未引出，不声明硬件报警输出和外部复位接口  |

禁止直接按表通电通信：图纸文字与网标互换，须连续性测量实物 pin2/pin3 并由供货方冻结线序。
