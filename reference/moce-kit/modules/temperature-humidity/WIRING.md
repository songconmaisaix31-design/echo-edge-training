# 温湿度传感器 V1：接线

适用硬件：V1.0，第一批/第二批图纸；以相同硬件修订为前提。

连接器：CN1。针号是图纸接点编号；未提供实物插口观察面或线色定义，必须按实物 pin1 标记确认方向。

| 针号 | 模块侧信号 |
|---|---|
| 1 | 3V3 |
| 2 | 冲突：图线 SCL / 文字 SDA |
| 3 | 冲突：图线 SDA / 文字 SCL |
| 4 | GND |

禁止直接按表通电通信：图纸文字与网标互换，须连续性测量实物 pin2/pin3 并由供货方冻结线序。

主控侧映射见所选平台的 Board；UART 按方向交叉，I2C/SPI 按同名信号连接。不同供电轨不能因接头相同而直通。
