# 气压传感器 V1：驱动接入

公共头文件：[bmp388.h](drivers/common/bmp388.h)。结构体、错误码、单位和缓冲生命周期以头文件注释为准。

调用路径：应用业务 → 本模块驱动 → 主控 BSP 公共 API → 平台适配 → SDK → 外设。具体端口、速率、地址、GPIO 方向/上下拉、ADC 参考值和缓冲在项目 config 中选择。

先完成平台启动和 BSP 初始化，再初始化所用协议/IO，最后初始化模块。异步传输完成或明确归还缓冲后才能复用/释放；停止失败不能当资源已释放。驱动未提供的操作不得猜函数名。

入口索引（自动摘录，完整签名以原头文件为准）：

```c
BspStatus bmp388_probe(Bmp388*,const Bmp388Config*);
BspStatus bmp388_init(Bmp388*,const Bmp388Config*);
BspStatus bmp388_measure(Bmp388*,Bmp388Reading*);
void bmp388_deinit(Bmp388*);
```

源文件依赖：`bmp388.h`、`bsp_i2c.h`、`limits.h`、`math.h`、`string.h`。C 库和 BSP 头由平台提供；需要 `math.h` 的功能在最终链接添加数学库。

| 参数 | 发布资料值 |
|---|---|
| 核心器件型号 | BMP388（TOKMAS），驱动及补偿算法按所附TOKMAS版本资料实现  |
| 气压测量范围 | 300～1100 hPa |
| 当前I²C地址 | 0x76，7位地址；SDO在板上固定接地  |
| 原始数据格式 | 压力、温度原始数据为24位二进制补码，需要符号扩展和补偿计算 bit |
| 数据补偿要求 | 读取器件校准系数，并使用与过采样配置对应的比例系数计算压力及温度  |
| 外部中断支持 | 当前板卡未提供外部中断接口；SDO固定接地，不启用其输出功能  |

I2C；VCC 允许范围待确认。
